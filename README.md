# REBOUND v41 – Winner Celebration
When a level is completed:
- Large 🏆 WINNER! 🏆 appears.
- Streamers/confetti, stars, sparkles and coins fall across the screen.
- The exact coin reward from that level is shown prominently.
- Final score is shown.
- Level coins and remaining lives are shown.
- Flawless runs call out the +25 bonus; one-hit runs show the +12 bonus.
All v40 compact kid-friendly home screen and v39/v38 gameplay features are retained.
