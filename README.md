# REBOUND v24 – Enhanced 3D-style graphics

- Side-scrolling gameplay across the phone.
- Uses the supplied full-body Peyton photo as the main runner sprite, including real legs.
- Enhanced 2.5D/3D-style theme park graphics: roller coaster, Ferris wheel, castle gate, layered sky, raised road/platform, dimensional barriers, ramps and gold star coins.
- Theme progression retained: Theme Park, Night Run, Ghost World, Soccer World, Alien World.
- Tap/click Jump button to jump; Slide button or downward swipe to slide.
- 3 lives, coins, level unlocks and finish line.
