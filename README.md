# REBOUND v19 – Behind-the-Runner 3-Lane Adventure

Major gameplay redesign:
- Camera now follows behind the runner.
- Swipe left/right to change between three lanes.
- Tap to jump and swipe down to slide.
- Obstacles approach the camera with perspective.
- Five themed worlds across 25 levels:
  1–5 Sunny Park
  6–10 Night City
  11–15 Haunted Run
  16–20 Soccer Stadium
  21–25 Alien Planet
- Each world has matching obstacles: hurdles/logs, aliens/barriers, ghosts/graves, soccer balls/goals, alien crystals/lasers.
- Gold coins, sounds, 3 lives, Peyton's blue/green dress and sprint animation retained.
