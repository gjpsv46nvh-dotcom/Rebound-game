# REBOUND v36 – Moving Worlds + Score Rewards
- Every level now uses a visibly different full-screen world, not just a tint.
- Background scenery scrolls at two speeds (parallax), plus moving road markings, so the runner feels like she is travelling forward.
- Theme cycle includes Theme Park, Night City, Sports, Zoo, Dinosaurs, Ghost, Ocean, Space, Jungle and Snow.
- Main character is cropped higher so the fixed photographed lower legs are removed; animated legs remain.
- End-of-round score added.
- Score includes distance, collected coins, remaining lives, completion and flawless bonus.
- Coin rewards now depend on performance:
  * Flawless (0 hits): collected coins + 25 bonus
  * 1 hit: collected coins + 12
  * 2 hits: collected coins + 5
  * 3 hits / failed round: no completion reward
- 25-level progression, Home Screen support and landscape fit retained.
