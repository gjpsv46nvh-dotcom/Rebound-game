# REBOUND v38 – Swipe Controls
- Swipe UP anywhere on the gameplay canvas to jump.
- Swipe DOWN to slide.
- Jump is approximately twice as high and stays airborne much longer, giving roughly twice the forward travel during a jump.
- Slide duration is approximately doubled, so the runner travels about twice as far while sliding.
- Moving themed backgrounds, score, flawless coin rewards, levels and Home Screen support retained.
