# REBOUND v39 – Runner Hub
Home screen additions:
- RUNNER, BOOTS, LEVELS and SHOP tabs.
- Six runners, with unlockable characters.
- Five boot choices with modest abilities.
- Permanent coin bank and coin shop.
- Photo picker: players can choose a photo from their phone and create a local custom runner.
- The selected photo is resized and stored locally in that browser/device; this build does not upload it to a server.
- Custom photo appears on the animated game runner as the player's face badge.
- Existing 25 levels, moving themes, swipe-up jump, swipe-down slide, scoring and flawless rewards retained.

Note: Fully transforming a photo into a new 3D/cartoon full-body runner would require an image-generation backend. v39 provides the privacy-friendly on-device version.
