# REBOUND v32 – Themed Levels
Each level now changes the world/background. Themes rotate through:
1 Theme Park
2 Night City
3 Sports World
4 Zoo Adventure
5 Dinosaur Land
6 Ghost World
7 Ocean Run
8 Space Run
9 Jungle
10 Snow World
Then the themed cycle continues across the 25 levels.

The selected theme is shown in the gameplay HUD. Existing landscape fit, Home Screen/PWA support, transparent cropped runner, levels, rewards, lives, coins, jump and slide are retained.
